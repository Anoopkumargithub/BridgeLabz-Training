# BridgeLabz-Training

## Collection Framework - C# Practice

This repository contains comprehensive implementations of data structure operations using C# collections framework. All implementations demonstrate practical usage of Lists, Maps (Dictionaries), Queues, Sets, and real-world system problems.

### Completed Implementations

#### List Interface Operations
1. **FindFrequencyOfElements.cs** - Generic method to find frequency of elements in a list using Dictionary
2. **RemoveDuplicateElement.cs** - Removes duplicate elements from a list while maintaining insertion order
3. **ReverseListUsingArrayList.cs** - Reverses an ArrayList using two-pointer approach
4. **ReverseListUsingLinkedList.cs** - Reverses a LinkedList by traversing from end to start
5. **RotateElement.cs** - Rotates list elements to the left by k positions

#### Map Interface Operations
1. **InvertAMap.cs** - Inverts a dictionary (swaps keys and values), grouping keys by value
2. **WordFrequencyCounter.cs** - Counts word frequencies in text with case-insensitive matching

#### Queue Interface Operations
1. **GenerateBinaryNumbers.cs** - Generates first n binary numbers using queue BFS approach
2. **ReverseQueue.cs** - Reverses a queue using an auxiliary stack

#### Set Interface Operations
1. **CheckEqualSet.cs** - Checks if two HashSets are equal using SetEquals()
2. **FindSubset.cs** - Determines if one set is a subset of another
3. **SymmetricDifference.cs** - Finds symmetric difference between two sets
4. **UnionIntersectionOfSet.cs** - Computes union and intersection of two sets

#### Real-World System Problems
1. **ShoppingCart.cs** - Shopping cart management system with:
   - Product price mapping
   - Insertion order maintenance
   - Sorting by price
   - Total calculation

2. **VotingSystem.cs** - Voting system with:
   - Vote counting per candidate
   - Vote casting order tracking
   - Sorted results display
